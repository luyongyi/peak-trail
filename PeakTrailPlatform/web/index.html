BEFORE THE ASCENT

下一次同行，记得留下足迹。

在游戏电脑上装好一个 Mod，回来就能沿时间重走整段旅程。

下载足迹 Mod ↓ v0.7.1 · 208 KiB · Windows 电脑 GitHub 备用下载 ↗
  1. 01

    先装好加载器

    关闭游戏。在 Steam 的 PEAK 页面选择「管理 → 浏览本地文件」，找到 PEAK.exe 所在目录。

    在 BepInEx 5 官方发布页 ↗ 下载 Windows x64 包 BepInEx_win_x64_5.4.23.3.zip，解压到这里，启动一次游戏后退出。已有 BepInEx 5 可跳过。

  2. 02

    放入一个 DLL

    下载上方的 PeakTrailRecorder.dll，放进游戏目录下的：

    BepInEx/plugins/

    升级时替换旧的同名 DLL，不要同时保留两份。无需另外下载地图，也不用再安装第二个足迹 Mod。

  3. 03

    开一局，再回来看看

    进岛后自动记录本机已同步的队伍足迹，无需游戏内开关；停留在机场不记录。文件保存在：

    BepInEx/PeakTrailRecordings/

    打开「我的足迹」，导入这个总目录，或选择其中的 PeakTrailHistory.ndjson。按日期、局次切换，拖动时间线回看。

↟

已验证 PEAK 2.4.c / BepInEx 5.4.23.3。Mod 只装在 Windows 游戏电脑上，观看者无需安装；一人可记录本机已同步的队伍信息，并非全知视角。手机、iPad 和桌面都能观看；手机和 iPad 回放需先把日志文件传到设备，再选择「历史日志文件」。

想让朋友实时观看？可选 · 默认关闭＋

装好 DLL 后先启动并退出游戏，打开 BepInEx/config/PeakTrailRecorder.cfg，仅修改对应配置项，再启动游戏。

进入对局后，朋友可在本网站的「现场观测」中选择正在进行的对局。改回 [Live] Enabled = false 并重启游戏即可关闭直播；本地记录可继续保留。

开启前请征得同局玩家同意。直播会上传昵称、稳定玩家 ID、位置与游戏状态，能访问本网站的人可观看。仅导入本地日志不会上传文件。

[Recording]
Enabled = true

[Live]
Enabled = true
ServerUrl = https://peak.mylus.cn
没找到日志，或安装后没有反应？＋

记录在实际对局开始后生成，只停留在主菜单还不会有足迹。确认 DLL 在 BepInEx/plugins/ 中，而不是留在下载目录或压缩包里。

若 BepInEx/config/PeakTrailRecorder.cfg 没有生成，先检查 BepInEx 是否正常加载；可查看 BepInEx/LogOutput.log 中的报错。已有配置时，确认 [Recording] 下的 Enabled = true。若自行修改过 OutputDirectory，请在设置的目录找日志。

已有记录怎么保留？如何卸载？＋

升级只需在关闭游戏后替换 DLL，保留原配置和足迹目录。旧记录可直接导入，不需要重新进游戏录制。卸载时关闭游戏，移走 PeakTrailRecorder.dll 即可；已保存的足迹不会因此删除。

日志含昵称、玩家 ID 与行程，分享给别人前请征得参与者同意。
