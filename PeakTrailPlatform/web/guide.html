FROM THE MAP TO THE MEMORY

导航与回放，按这几步开始

网站导航直接使用房间号。游戏内回放仅支持 Windows 与正版 PEAK 3.0.1。

PEAK NAVIGATION浏览器使用

先打开本局导航

  • 01
    输入六位房间号

    在导航服务填写当前联机房间号。请征得同房玩家同意，并预留一个玩家名额。同房间多人输入会复用同一个任务。

  • 02
    查看和分享地图

    等待连接后打开导航地图。分享本次地图链接，其他人即可查看同一份数据。关卡切换会继续导航。

  • 03
    下载本次录像

    散场、断线或管理员停止采集后，在导航历史下载 ZIP。每位房主保留最近 2 份，超过 7 天删除；历史入口保存在当前浏览器。

NATIVE GAME REPLAYWindows Only

再在游戏内回放

  • 01
    准备正版 PEAK 3.0.1

    在 Windows x64 上安装正版 PEAK 3.0.1，保持 Steam 登录，并先退出游戏。首次准备需要足够空间复制本机游戏资源。

  • 02
    解压 Windows 回放组件

    将组件完整解压到普通可写目录，按 README 操作。不要放进游戏安装目录；原 Steam 游戏目录保持原样。

  • 03
    选择 capture.peaknet

    解压录像 ZIP，将 capture.peaknet 拖到 Play-Replay.cmd，或双击它选择录像。自动查找游戏后准备独立回放副本；找不到时选择 PEAK.exe。进入后自由飞行，F 跟随，Tab 切换玩家。
