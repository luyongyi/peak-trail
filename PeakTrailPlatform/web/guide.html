FROM THE MAP TO THE MEMORY

导航与回放，按这几步开始

Windows 游戏内回放需要与录像匹配的 PEAK 版本。

PEAK NAVIGATIONPEAK 3.1

先打开本局导航

  • 01
    输入 8 位房间号

    请征得同房玩家同意，并预留一个玩家名额。同一房间共享导航。

  • 02
    查看和分享地图

    等待连接后打开导航地图。分享本次地图链接，其他人即可查看同一份数据。关卡切换会继续导航。

  • 03
    下载本次录像

    散场后可在导航历史下载 ZIP，也可按录制时的房主昵称查找。每位房主保留最近 2 份，最长 7 天。

NATIVE GAME REPLAYWindows Only

再在游戏内回放

  • 01
    准备游戏与 BepInEx

    需要 Windows x64、正版 PEAK 3.1.0 和 BepInEx 5。安装前请退出游戏。

  • 02
    安装回放组件

    解压组件，将其中的 BepInEx 文件夹合并到 PEAK 游戏目录。

  • 03
    在游戏中播放

    保持 Steam 登录。在主菜单打开“录像回放”或按 F8，按房主昵称查找录像，也可选择下载的录像 ZIP。
