# 每日插画首页 · 2026-09-23

首页保留四个主关卡，以统一手绘风格的 AI 插画呈现主题；不再在首页加载模型预览。
点击关卡才进入真实地图。Roots 的中文显示统一为「森蕈」。

## 插画与资源边界

- 当前仅支持 iPad 和桌面布局；不维护手机专用样式与手机验收。
- iPad 竖屏（744–1100 CSS px）两列，横屏与桌面四列；大型 Pro 竖屏也采用两列。
- 原有手机缩字、隐藏日期、压缩按钮规则已移除；下方手机验收仅是历史记录。
- 七个主主题：海岸、森蕈、雨林、雪山、台地、火山、雾岛。
- 两个终章：熔炉（火山内部）、城塞（高塔内部），共九张 1024×1536 PNG。
- 内置 image_gen 生成，海岸图作风格参考；完整提示词在 `home-art-prompts.json`。
- 原图复制到仓库总目录内的 `local/assets/home-art`；Git 忽略，需独立备份。
- `web/src/home-art.js` 是唯一发布白名单，staging 不复制旁边的私人日志或其他文件。
- 插画明确标注「非地图实景」，不用于坐标、每日地图识别或回放定位。

## 第四关轮廓修订（v2）

用户指出火山、雾沼（Swamp）的主地形应低平。对照 build `25306743` 的全部
21 套高度场，以及 Level_2 / Level_17 第四关的原始 GLB 后，修订两张插画：

- Level_2 火山：实际熔岩平面约 475×630m、海拔 780m；76.4% 有效高度样本
  在 770–790m。两类合计 300 个熔岩柱顶端中位高于熔岩面约 15m、19m。
  11 套火山高度场中央 90% 高度跨度为 32.6–39.2m。
- Level_17 雾沼：实际地形网格 32,258 个三角形；按水平投影面积加权，63.9%
  坡度低于 15°。水面约 775.5m，主要岩柱顶端中位只高出水面约 1.7m，90%
  分位约 7.9m。10 套雾沼高度场中位均约 775.8–776.7m。
- 高度场取最高碰撞面，包含岩石、水面等；不能把这些比例等同玩家可行走面积。
  少量独立高柱、外围与远端丘陵仍存在，不将其夸大成连绵高山。
- 内置 image_gen 以各自旧插画为编辑目标，保留画风，重做为「低平主体＋局部
  小岩丘」。使用 `volcano-v2.png`、`swamp-v2.png`，其余七幅不变。
- 旧 v1 与原提示词保留供回溯，但不在发布白名单；提示词文档记录当前版本及
  supersededAssets。`segment 4` 的熔炉/城塞插画及所有真实模型、DLL 均未修改。

## 路线和交互

每日观察需要合法序号、场景、槽位、时间及精确 build/mapPack 身份。时间过期会明确
降级到「上次确认的四关」。不按日期、奇偶、图案或上一局日志猜测本轮路线。

真实分支决定终章：火山 → 熔炉，雾岛 → 城塞。四关下方默认展开本轮终章插画，
用户可自行收起，倒计时更新不会反复展开；分支变化时默认展示新的对应终章。
首页的地图包独立于历史日志；进入首页地图暂时离开回放，
再次点「我的足迹」恢复之前选择的本地会话。
