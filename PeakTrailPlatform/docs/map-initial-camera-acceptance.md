# 地图初始视角修复验收

2026-10-07。基于新版原生地图发布，修复从首页进入地图时的空视图和取景范围。

## 原因

原相机要等完整 GLB 加载后才定位。Level_17 海岸中心在初始相机后方；雨林、雪山和雾沼也不在初始视锥内。加载中点击画布会增加相机操作 revision，最后的定位随之跳过。

原最大边长取景近似没有计算实际透视投影。真实 Level_17 范围验算：16:9 海岸角点 NDC Y=1.528，9:16 X=1.363，超过画面边界。窗口尺寸变化和高度比例变化也没有更新预设镜头。

## 修复行为

- 加载前立即按所选关卡源边界定位，完成后按源地标外壳或天底实际边界适配；后续手动操作仍拥有镜头。
- 用全部八个边界角点与横、纵视场计算距离，默认保留 8% 角宽余量。近远面与轨道距离限制按实际取景计算；清理旧镜头阻尼后赋值。
- 窗口、路线栏和高度变化只重新适配未手动移动的预设镜头；自由相机和玩家跟随保持。
- 从首页再次进入同一关，即使模型数据缓存命中，也恢复默认视角。地图浏览中的城塞默认显示完整外观，仍可手动“进入关内”；新录像回放保留自动关内参考点逻辑。
- 同一录像底图更新保持显示原点及手动、自由和跟随所有权；先重建玩家标记，再等待模型，避免加载空档被判断为玩家离开。
- 加载期间显示“地图加载中…”，正常地图界面仍保持简洁。

## 验证

Web 语法和静态入口检查通过，532 项测试全部通过。新增覆盖真实新版地图代表范围、横屏/竖屏/极窄视窗、高度比例、Z 镜像、俯视、下载延迟、加载中手动操作、尺寸变化、缓存重入、城塞地图浏览，以及同录像自由/跟随镜头保持。

使用实际 vendored OrbitControls 注入旧平移、旋转和缩放验证，目标及相机漂移小于 1e-12 m，八角点最大 NDC 约 0.926。俯视极点保护产生约 2.3 mm 偏移，仍在边距内。

本地浏览器已确认海岸和城塞默认可见，城塞在 390×844 竖屏中保持完整可见，控制台无 warning/error。最终上线状态与线上截图保存在本次本地部署回执中。

## 2026-10-19 全地图近景复评

旋转后的局部包围盒先扩成世界轴对齐包围盒，再用于取景，会把并不存在的空角算进屏幕范围。现在保留实际 indexed draw range 的局部包围角点，经实例矩阵直接转换用于透视计算；用于主体聚类的原有世界包围范围独立保留。天底同样保留各个非水面部件的方向，仅在已有材质、shader 和 5 km 尺寸全部匹配时排除水面取景约束。

生产视角使用 `padding=1.02`，给顶部常驻控件单独保留不对称安全区域。平板的收起导航移至工具栏同行；横屏手机也压成同一行，场景信息收紧到左下角。导航切关时的临时展开不增加取景距离。手动镜头所有权、源坐标、轨迹边界、几何可见性和 FOV 保持原有语义。
