# 地图基础雾与轨迹遮挡修复

## 来源与实录边界

当前游戏构建 `25306743` 的 21 套地图中，10 套为雾岛—城塞分支。原始 `StatusFieldGloom` 不一定在关卡根节点下；雾岛的 `SleepyFog` 位于共用父节点，因此之前只导出分区子树时漏掉了雾体。现在从原始场景提取范围、初始高度与源材质，将小型元数据按构建、场景文件 SHA 和地图包身份绑定后加入生成站点，原有规范化几何及其 ID 不变。

页面严格区分：

- 没有世界实录的旧日志：显示“地图基础雾 · 初始配置，非本局实录”。不推测本局雾层升降、灯光安全区或难度状态。
- 已有世界实录：只按日志回放，包括空快照；不补基础雾，不提前显示未来采样。
- 关闭世界与雾层：移除体积展示，并恢复此前隐藏的原始雾面。

原有 GLB 的纯 `FogSurface` 批次按同关、同构建的已核实地图元数据替换。有实录时，即使当前实录世界为空或雾已移动，也不会残留固定的初始雾面；没有映射证据则不猜测关联。水、虚空雾、混合材质和不同构建的材质不受影响。

## 视觉与坐标

雾使用源地图范围与源色，仍是浏览器的体积近似，不声称复刻 Unity 着色器。可见雾启用场景深度预渲染，体积积分在首个不透明表面终止，避免把近处物体与远处山体均匀染色。原始世界 XYZ、高度缩放和灯光保护区使用同一个坐标系。

路径以两组互补深度条件绘制：可见线约 92% 不透明度，遮挡线约 18%，遮挡部分不附加强描边。人物位置标记同样区分遮挡；相机接近标记时隐藏标记，移远自动恢复，不改变路径或位置数据。

单关以原始层级的空间范围裁剪轨迹；坐标既不贴屋顶，也不投影到地面。城塞调查、人物中心语义及重叠边界限制见 [城塞轨迹调查](citadel-trail-audit.md)。

## 自动验证

新增或扩展的测试涵盖：源雾身份绑定、所有分支配置、空实录与时间回退、世界开关、雾面安全恢复、源色、远程及本地地图加载、场景深度预渲染与资源生命周期、双深度轨迹、共享线段几何、精确空间截断、相机中心坐标及近处标记隐藏恢复。

所有自动测试的玩家与轨迹数据均为合成数据；实际本机日志未进入 Git 或站点产物。本轮没有修改、安装游戏 DLL。

本轮结果：前端 212 项、工具 10 项、离线地图 Python 11 项全部通过，静态入口和语法检查通过。重新构建的 21 地图站点约 918.2 MB，未包含私人记录。

浏览器使用本机同一局旧日志复核：雾岛 33:20 的雾内视角和分关视图均出现基础雾，深度修正后近处地面保持颜色、远处逐渐被雾覆盖；城塞 44:10 使用记录中心参考位置，近处自身标记不再堵屏。浏览器未见着色器编译错误或其他 warning/error。这是网页回放验证，不是 0.6 DLL 新游戏运行验证。
