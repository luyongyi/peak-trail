# 0.8.2 直播路线持久保存与原生终局

- 直播开启时独立保存 10 Hz 紧凑路线；关闭完整录像不影响这份路线归档。
- 原生切关、传送、个人进度、天底魂阶段和获胜即时采样并同步磁盘，普通采样每 900 ms 同步。
- 切关、个人进度和结束时后台压缩、上传累计前缀；失败保留本地文件，下次启动直接从未封口日志恢复。
- 关闭直播立即停推流、清直播码，已保存的路线继续排队上传。日志在上传成功后也保留。
- 使用 Memories 0.8.36 相同的对局/玩家散列及共享时钟，保留真实地图标志、进度门、难度和路线断点。
- 只把原生个人 `won` 与 `wonViaNadir` 作为登顶/天底终局证据；拿到物品、进入 Void、打开墙与追逐阶段各自区分。
- 原生本机进度只标记存活且未传送的本机玩家，不把全队切关当成所有人的通关。
- 新增路线归档契约及可供服务端验证的 synthetic fixture，覆盖崩溃尾行、启动续传、重试、身份晚到、同帧阶段、原生终局和容量边界。

本地路线目录为 `BepInEx/PeakTrailRoutes/`。服务端容量或导出内存预算超限时保留原日志并写 pending-budget 状态，不截短路线或删除未上传记录。仍需配套支持新增原生里程碑和位置锚点的服务端。
