# PeakTrailRecorder 0.7.1

PEAK Trail 的单 DLL 足迹记录 Mod。已验证环境：Windows x64、PEAK 2.4.c、BepInEx 5.4.23.3（Mono）。只需安装 `PeakTrailRecorder.dll`，无需第二个地图 Mod；此发行版不包含游戏资源、游戏程序集、私人日志或配置。

## 安装与使用

1. 退出 PEAK。Steam → PEAK → 管理 → 浏览本地文件，找到 `PEAK.exe` 所在目录。
2. 没装过 Mod 时，先从 [BepInEx 官方发行页](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.3) 下载 `BepInEx_win_x64_5.4.23.3.zip`，将内容解压到游戏根目录，启动游戏一次后退出。已有 BepInEx 5 的用户无需重复安装。
3. 把下载的 DLL 放到 `BepInEx/plugins/PeakTrailRecorder.dll`。升级时替换旧文件，不要保留两份不同名字的同一插件。
4. 进入岛屿后自动记录。到 [PEAK Trail](https://peak.mylus.cn/) →「我的足迹」，选择 `BepInEx/PeakTrailRecordings` 总目录，或拖入其中的 `PeakTrailHistory.ndjson`。网页会拆分多天、多局，导入在浏览器本地解析、不上传。

一名记录者可记录其客户端已经同步到的队友数据，不要求所有队友安装。不能还原本机未观察到的状态。iPad 只用网页观看，不安装 DLL。

## 可选：在线观测

直播默认关闭。先运行一次装有本插件的游戏，再退出，打开 `BepInEx/config/PeakTrailRecorder.cfg`，只修改 `[Live]` 段：

```ini
[Live]
Enabled = true
ServerUrl = https://peak.mylus.cn
```

保存后重新启动游戏进入岛屿。在网站首页「现场观测」选择活跃对局。旧配置不会被新版 DLL 自动覆盖，升级用户需手动更新旧服务器地址。保留 `[Recording]` 的 `Enabled = true` 才会继续本地录制。

开启直播会将队伍昵称、稳定玩家 ID、位置和状态等发送到服务器，网站访客可查看；请先获得参与者同意。四位对局码不是密码。不开直播也能完整使用本地回放。
