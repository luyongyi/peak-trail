# 0.8.1 四位直播码

- 游戏原生「设置 → 通用 → 直播码」显示四位大写字母，例如「ABCD · 点击复制」；点击只复制这四个字母。
- 观众在网站输入直播码即可观看，无需注册或登录。原有观看链接和游戏内「直播观看链接」按钮继续保留。
- 同场发布者和待命队友显示相同直播码，自动租约接管不会换码；已结束后的新会话可以获得新码。
- 关闭直播立即清除显示并禁止复制；旧的「已复制」提示不会遮住关闭状态。后台请求取消时也会立即清空观看信息。
- 直播码由中继分配，只接受四位 `A–Z`。旧中继缺少直播码时仍可使用观看链接，不会显示上一会话的旧码。
- 新安装每局默认直播、即时开关、局内临时玩家编号和独立推流凭证保持不变。

## 配套与验证

- 配套 v2 中继的注册成功 `201` 和待命 `409 publisher-active` 响应提供 `watchCode`；网页提供直播码输入。
- 直播码只用于观看，不作为推流凭证，也不启用旧 `/api/runs` 上传协议。
- 定向契约覆盖注册成功、待命同码、接管保码、会话结束换码、无效或缺失码、旧链接兼容及停止清理。
- Recorder solution Release 构建通过：0 警告、0 错误；八个 C# 契约工程全部通过。
- 本次四位码按钮的实机原生设置验收另行记录，不以传输契约代替游戏内验证。
