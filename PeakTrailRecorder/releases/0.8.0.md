# 0.8.0 路径直播开发构建（未公开发布）

- 新安装默认在每个可游玩对局开启直播，保留用户已经保存的开关偏好。
- 游戏原生「设置 → 通用 → 路径直播」即时开启／关闭并保存；主菜单、暂停菜单使用同一设置。
- 同页复制只读观看链接。观众通过链接直接进入地图，不需要注册、登录或手动开播。
- 多人安装时自动采用单端推流和租约接管，不重复广播全队数据。
- 使用独立推流凭证和局内临时玩家编号，直播不上传原始平台 ID、录像或世界对象数据。
- 修复注册前状态丢失、采样受文件频率限制、过量小请求、丢 ACK 重试、长断流恢复、停止时等待网络。
- 新观战页支持实时／近期回看、玩家跟随、连接状态、链接过期提示和有界缓存。
- 服务端按序号恢复、独立保留玩家当前状态及加入／离开／生死事件，对慢观众和总缓存设置字节上限。

## 验证

- Recorder solution Release 构建：0 警告、0 错误；8 个 C# 契约工程通过。

- 本地合成轨迹经真实 HTTP 中继 → 同源预览 → 浏览器，验证匹配地图、实时推进、回看和玩家跟随。
- 未测真实多人对局的长时间帧耗时；此构建未作为公开 Release 发布。

默认公网地址为 `https://peak.mylus.cn`，本轮未切换线上服务。
当前会话为内存态，中继重启后 DLL 会重新注册，观看链接可能变化。
